Drop the USSF Unity webfont files here and the display type switches on
automatically. ussf-as.css already declares them:

  USSFUnity-Bold.woff2            (and .woff)
  USSFUnity-CondensedBlack.woff2  (and .woff)

Without these files the pages fall back to Arial Black / Arial, which is
what the current renders show. Body copy is Arial either way, matching
the template.
